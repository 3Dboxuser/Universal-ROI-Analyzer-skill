# 计算口径与脚本输入

## 建模边界

先固定比较基准、分析主体、币种、日期、期限、每期长度、税前/税后及名义/实际价格口径。未来税款使用实际适用规则；缺失就注明未计税或提供条件区间。未知折现率不能默认为零后当作有依据的 NPV。

输入是**相对于基准的增量**：额外收入或少付的钱列现金收益 B；额外支出或少收的钱列现金代价 C，均用非负金额。它们不是会计营收和费用的替代品。收入减少若已列 C，不再列相同机会成本。

尚未兑现的营收按预计收款时点计入。融资流入不是项目收益；项目视角先算融资前经营/投资现金流，股东视角单独建模，不混入借款制造正 ROI。押金、库存等占用按实际支付和释放记现金流，不能同时全额再计机会成本。期末残值须有可实现依据，处置费、退出支出和末期负债也应入账；期末以后仍存在的责任明确披露。

复杂融资、非等间隔日期、税务或复杂资产交易需要另建模型；不要为了使用脚本而改变经济含义。

## 指标

对 t=0…T：
- 净现金收益 = Σ(B_t − C_t)。
- 现金 ROI = Σ(B_t − C_t) / ΣC_t。这里分母是**全评估期增量现金代价**，不是只用初始投入，也不是年化收益。分母为零则未定义。
- 可估价经济净收益 = Σ(B_t + V_t − C_t − O_t)，V 为未计入现金的可估价收益，O 为未重复计算的机会/非现金成本。
- 可估价经济 ROI = 上式 / Σ(C_t + O_t)，单列估值假设；不能称为现金 ROI。
- NPV = Σ CF_t / (1+r)^t；CF 可分别取净现金或可估价经济净收益。r 是**每期**有效折现率。年有效利率换月有效利率：r月=(1+r年)^(1/12)−1。名义现金流匹配名义率，实际现金流匹配实际率。
- 增量资金缺口 = max(0, −min_t Σ_{i=0}^t CF_i)。只有期末数据时无法捕捉期内资金峰值；现金是否足够还取决于原有现金、基准运营支出及可用融资。
- 回本：脚本报告首次累计现金从负转非负的期末，以及在剩余建模期间保持非负的回本期末。不做期内线性插值，不代表期限外不会再亏。累计现金从未为负时标“不适用”。
- 单位贡献 = 单价 − 单位变动成本；同一期经营盈亏平衡量 = 固定经营成本 / 单位贡献。贡献≤0且存在固定成本时没有有限正销量解。固定成本为零、贡献为零时属于零利润特例。整件商品需向上取整；此指标不能代替收回初始投资的计算。
- 有概率时 E[净收益] = Σp_s × 净收益_s；不把平均 ROI 当总体 ROI，不用均值掩盖损失。概率必须描述互斥且完备的结果集合，否则只能展示情景。

不可估价的体验、健康、关系等保持自然单位与定性判断；不能塞进 V/O 凑出经济 ROI。IRR、年化 ROI、模拟分位数不由此脚本提供，确有必要时单独验证其假设及多解问题。

## 脚本使用

从 Skill 根目录运行，Python 3 标准库即可：

```bash
python3 scripts/roi_calculator.py /absolute/path/input.json --output /absolute/path/result.json
```

不传 `--output` 时输出到终端。输出路径若已存在会报错，避免误覆盖。此脚本只计算已给定数字，不负责联网、估价、证明因果或验证概率。输出中的 `null` 代表未定义、未提供或期内未发生，需结合对应字段和 `payback_status` 解读，不能显示为零。

### 输入结构

顶层必填：`currency`（币种）、`period`（每期单位）、`baseline`（比较基准）、`scenarios`。
可选：`discount_rate_per_period`（每期有效率，必须大于 −1；缺省不算 NPV）。

每个情景必填：
- `name`：唯一名称。
- `cash_benefits`、`cash_costs`：非负金额数组。第 0 项现在发生，之后每项为等间隔期末；包含零期和至少一个未来期。所有情景长度一致。

每个情景可选：
- `noncash_benefits`、`opportunity_costs`：同长度非负金额数组；省略仅表示模型未纳入，不是已经证实为零。
- `hours`：同长度非负投入工时数组，仅报告，不自动货币化。省略则工时未知。
- `probability`：0–1；有任何一个提供时必须全部提供且和为 1。每个同时提供非空 `probability_basis`，描述来源或用户设定。脚本不验证依据的可信度。

不支持的字段、负值、字符串金额、布尔值、非有限数、不一致期间、重复情景和无效概率会报错。复杂业务指标在外部推导成账本，相关公式和原始参数另附。

### 合成示例（仅验证流程，不是市场数据或项目建议）

```json
{
  "currency": "CNY",
  "period": "月",
  "baseline": "保持现状；示例只展示相对于现状的增量",
  "discount_rate_per_period": 0.01,
  "scenarios": [
    {
      "name": "基准（合成数据）",
      "cash_benefits": [0, 800, 1200, 1600],
      "cash_costs": [2000, 200, 300, 400],
      "opportunity_costs": [600, 300, 300, 300],
      "hours": [20, 10, 10, 10]
    }
  ]
}
```

此例：现金收益 3600、现金代价 2900、净现金收益 700、现金 ROI 约 24.14%、资金缺口 2000、第 3 月期末回本；含假定机会成本后的经济净收益为 −800。它展示“现金盈利”与“含机会成本是否值得”可能不同。未提供概率，不计算期望收益。

## 敏感性与复算

先建立原始驱动（如销量、单价、采用率、人工复核比例）到 B/C 的公式，再在有来源的范围内改变驱动，重复运行账本。不能只缩放最终 ROI。保存参数范围、计算方法、关键临界值和约束。多方案比较时每个方案均相对同一基准；现金流不应把基准重复扣两次。

## 方法参考

以下用于核对评估方法，不是任何具体项目的价格或成功率证据；检索于 2026-09-08。应用时需重新查相关时效数据。

- [美国 SBA：商业计划与盈亏平衡分析](https://www.sba.gov/counseling/plan-your-business/)：用于核对固定成本、单位贡献及盈亏平衡量口径。
- [英国财政部：Green Book 2026](https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government/the-green-book-2026)：参考备选项评估、敏感性分析和不确定性处理思路。其公共项目参数与社会折现率不直接套用于个人或商业项目。
