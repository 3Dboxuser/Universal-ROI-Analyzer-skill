# 条件与领域检查表

只选与当前选择有关的条目。检查表用于发现盲点，不是给每个想法强加所有风险。

## 共通盲点

| 维度 | 检查内容 |
|---|---|
| 真实需求 | 谁实际需要、谁使用、谁付钱？兴趣能否转成付费或持续使用？ |
| 转化链 | 哪一步是瓶颈？基准成功率来自怎样的样本？只看到成功者了吗？ |
| 可用资源 | 声称可投入的时间是否扣除了本职、休息和家庭责任？技能和执行力有证据吗？ |
| 全生命周期 | 学习、准备、迁移、集成、运行、监督、返工、维护、升级、退出需要什么？ |
| 资金与时序 | 押金、预付款、库存、应收款、退款、税费何时发生？收入晚于支出多久？ |
| 依赖与议价 | 平台、供应商、关键人员、许可、渠道、合作方退出或涨价会怎样？ |
| 不可逆性 | 能否转售、回退、恢复旧流程？合同、资产和声誉是否长期绑定？ |
| 替代与机会 | 不做会怎样？更便宜、更快的方案能否达到同一目标？拖延有什么成本？ |
| 外部影响 | 代价是否转嫁给家人、同事、客户或环境？用户收益是否以他人损失为前提？ |
| 失败与恢复 | 失败后还剩什么可复用资产？清理、解约、数据迁移、恢复要付多少？ |
| 选择权 | 小试能否用少量成本保留扩大或退出机会？等待会失去哪项机会？ |

## AI / Agent 项目

- 数据是否存在、质量是否合格、是否有权限使用；数据清洗、标注、接入与更新成本。
- 自动化的任务边界、实际成功率、异常比例、人工复核与兜底工时；平均成功率不能替代高损失错误分析。
- 模型/API、token、检索、存储、执行环境、第三方工具、并发、重试、评测、监控成本。免费额度/试用价不当作长期价格。
- 效率提高能否转化成现金：节省 10 小时不自动等于少付 10 小时工资。计算采用率、使用频率、结果可用率及监督时间。
- 误操作、幻觉、数据外泄、工具权限、对外承诺与修复责任，仅纳入实际可达的风险路径。
- 模型变更、供应商中断、版本升级、流程变化的维护成本；相较于现成人工流程和简单规则自动化的增量价值。

## 创业 / 副业 / 商业项目

- 自下而上推导：触达量 × 有效线索率 × 转化率 × 客单价 × 复购/留存；用交付能力封顶。
- 获客成本、毛利/贡献毛利、退款与坏账、流失、收费平台规则、售后和创始人工时。
- 市场规模不等于能获得的收入；营收、利润和可分配现金分别计算。
- 许可、税费和合同条件按实际地区查证，不把其他地区案例直接套用。

## 购买 / 学习 / 职业

- 购买：全拥有成本、使用频率、耗材、维修、兼容性、残值；租借、二手或继续现状。
- 学习：基础要求、学习与练习小时、完成率、能力验收、技能使用场景；证书不等于就业或涨薪。
- 职业：税后总报酬、福利、通勤、工作时长、稳定性、成长、迁移成本；避免假定一定拿到 offer。

## 健康 / 生活 / 关系

- 使用与目标一致的自然指标；偏好来自用户，不自行给健康、尊严或关系标价。
- 考虑适应期、可持续性、相关人的同意和实际影响。不要用“ROI 高”作为操控他人的理由。
- 涉及具体医疗方案或法律权利时，用当前权威资料标明适用范围；关键专业判断缺失则把它作为决定条件，不用经济收益替代该判断。
