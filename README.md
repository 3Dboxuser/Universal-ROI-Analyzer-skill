# Universal-ROI-Analyzer（万事万物ROI得失计算器.skill）
在承诺投入之前，先把账算明白

Decision-grade AI skill for evidence-backed ROI, hidden costs, scenario analysis, and actionable next steps. 
决策级人工智能技能，用于提供基于证据的投资回报率、隐藏成本、情景分析和可操作的后续步骤。

**一个决策级 AI Skill：把任何想法转成有证据支撑的 ROI 分析，明确你能得到什么、真正要付出什么、哪里可能失败，以及最值得先做的下一步。**

[English](README.md) · [它解决什么问题](#它解决什么问题) · [如何使用](#如何使用) · [它如何思考](#它如何思考) · [许可证](#许可证)

大多数 ROI 计算器只问：**“回报是多少？”**

Universal ROI 继续问那些真正决定回报是否存在的问题：

> 如果什么都不做，会怎样？谁真正受益？它会消耗多少现金、时间、注意力与替代机会？哪一个假设足以让计划失效？成功、失败和安全退出分别是什么样？

它为需要做决定的人而写，不是为了制造一张看上去很漂亮的表格。

## 它解决什么问题

给它一个想法、目标、约束和现有数据。它会研究真正影响决定的事实，严格区分证据与假设，并交付一份能行动的决策报告。

它包括：

- **真实收益**：收入、可实际减少的支出、时间、资产、技能、选择权及其他结果，并明确由谁得到、何时兑现。
- **完整代价**：启动、运营、维护、返工、税费、手续费、资金占用、退出、时间、注意力、压力和机会成本。
- **三种可辩护的未来**：最好合理、基准、最坏合理情景，以及每种结果成立的条件；不编造“保证成功”。
- **隐藏依赖**：需求、转化、产能、数据、权限、供应商、合同、采用率、可逆性及失败的早期信号。
- **决策路径**：现在行动、先小试、补关键证据，还是停止；每种路径都有检查点、预算与退出条件。
- **可复算数字**：内置 Python 计算器可计算增量现金 ROI、NPV、回本期、期末资金缺口、考虑机会成本后的指标；只有在概率确实可辩护时才计算概率加权结果。

## 如何使用

把此文件夹放入 Codex 的 skills 目录，或让 Codex 读取其中的 `SKILL.md`。之后直接自然描述你的问题：

```text
请使用 $universal-roi 评估：

我想做一个 AI 副业，每周能投入 8 小时、预算 5000 元，
希望六个月内产生收入。请查证需求和真实成本，给出我可能得到什么、
最好/基准/最坏结果、隐藏条件，以及最低成本的验证方案。
```

它适用于 AI Agent、创业、副业、购买设备、学习课程、换工作、搬家、流程改造或个人选择。它会按决策类型选择合适指标，不会假装生活的每一部分都必须折算成人民币。

### 可选：使用计算器

计算器不需要第三方依赖：

```bash
python3 scripts/roi_calculator.py /absolute/path/input.json --output /absolute/path/result.json
```

输入格式、公式和合成示例见 [`references/calculation.md`](references/calculation.md)。它只计算你提供的数字；它不会凭空制造证据、验证市场，也不会把不确定的猜测伪装成事实。

## 它如何思考

```text
想法 + 目标 + 约束 + 数据
              ↓
与真实替代方案比较：不做 / 换一个方案 / 先做小试
              ↓
查证那些足以改变决定的关键假设
              ↓
建模增量收益、完整成本、时间节奏与约束
              ↓
压力测试：最好合理 / 基准 / 最坏合理
              ↓
形成有条件的决策，并设计成本最低、信息量最大的实验
```

这个 Skill 遵守五条硬规则：

1. **不伪造精确。** 未知就是未知；估算必须带范围和来源。
2. **不重复计数。** 现金回报、已货币化的非现金影响、不能合理定价的价值分开处理。
3. **不把乐观当作基准。** 每个情景都必须写明它成立所需的条件。
4. **没有基准就没有 ROI。** 每个结果都相对于一个可信的替代方案计算。
5. **分析不等于替你执行。** 它提供行动路径；购买、发消息、交易和改变外部系统仍需要用户授权。

## 适合谁

适合需要决定要不要做产品的创业者、考虑要不要自动化的运营者、正在买、学、换、等的人，也适合每一个已经听到“肯定值得”，但仍然不知道真实代价的人。

请避免只为单一故事增加规则。好的贡献应让未来的决策更诚实、更可复算，或更容易采取行动。
